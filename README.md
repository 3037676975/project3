# Payment Lab 通用支付模板

这是一个可复制的支付宝 + 微信支付模板项目。

目标：以后开发任何新项目时，参考本项目结构，直接复制支付模块，不调用本项目接口。

## 已支持能力

- 支付宝当面付真实二维码
- 微信扫码支付模板
- 支付配置后台
- 异步通知处理
- 主动订单查询
- 支付状态管理
- 日志中心

## 项目结构

```
project3
├── public
│   ├── dashboard.php    控制台
│   ├── orders.php       订单管理
│   ├── logs.php         日志中心
│   ├── settings.php     支付宝配置
│   └── wechat-settings.php 微信配置
│
├── app/payment          支付模块（复制到其他项目）
└── storage              配置和日志
```

## 新项目接入方式

复制支付模块：

```
app/payment
```

根据业务订单接入创建、查询、通知逻辑即可。

不要把支付密钥写入代码仓库，只通过后台配置保存。

## 宝塔部署

1. 拉取仓库
2. 网站目录设置 `/public`
3. PHP 8.0+
4. 开启 curl、openssl
5. 保证 storage 可写

## 适用项目

- 会员系统
- 商城
- SaaS
- 充值系统
- 下载站
- 其他需要支付的网站
